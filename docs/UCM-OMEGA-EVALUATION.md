## 二、史料输入建议

每条史料保存 `id`、事实主张、时空范围、证据出处、年代精度、出处可靠度、同一事实的不同记载、可争议性、许可证信息。绝不可因为数据集名称权威就把全部条目作为百分之百正确的信史。

优先级建议：

- **一级**：可核实的一手历史文献、文物与同行评审研究，有明确版次及历史测年。
- **二级**：结构化权威数据集及其给出的原始来源、变量定义、样本范围。
- **三级**：多来源百科事实；每个事实都应保留来源、精度与争议标记。
- **模拟层**：用户直接设定的干预和模型生成的结果，永远不等同于史料层。

Seshat 的数据和特定快照可能具有独立许可及非商业限制；接入前逐个版本核查使用条款。公开软件采用 MIT 许可**不代表**可以把所有外部数据库任意并入仓库。Wikidata 的事实来源、限定词也必须在读取后保留，而不是忽略它们造成时间错配。

目前项目基线仅包含精选节点，无法支持“全世界数千年每个国家/地区”的高可信状态初始化。应先增加含引用的史料基础，再讨论真正的数据拟合和因果识别。

## 三、最低验收与分层评分

| 评测维度 | 具体测试 | 发布标准建议 |
| --- | --- | --- |
| 纪年与分支 | BCE/CE、无 0 年、同年事件、祖先截断、旧档迁移 | 边界性质测试全部通过 |
| 历史输入分类 | 精确年代、朝代末期、数量词、英文后置 BC/BCE、模糊地点、复合命令 | 自建带人工标注的数据集；按字段统计精确率、召回率 |
| 因果完整性 | 引用未来事件、无效前置技术、循环、矛盾事实、被拒因果祖先 | 预设反例必须全被拒绝；错误原因可追踪 |
| 数值机制 | 单位、守恒、参数与极端边界、干预前相同外生冲击 | 每个模型各自定义数值误差阈值 |
| 社会历史拟合 | 以可观测历史序列回测经济、人口等模型 | 数据外验证，不能只拟合已知轨迹 |
| 模型鲁棒性 | 改变提示词、模型、温度、情景数、时间窗 | 报告结论分歧和假设敏感性 |
| 成本与性能 | 总 tokens、响应时间、取消恢复、失败 API 重试 | 明确预算；真实用户环境测试 |
| 资料可信度 | 参考文献可打开、时间适用范围正确、许可证可用 | 无“模型自编来源”进入信史数据库 |

针对复杂社会反事实，检验指标不宜直接用“与现实 A 线完全一致”，因为用户已经改变了世界。应该使用**留出历史片段的回放实验**：只给定某一时间节点以前的数据，让模型在未人为干预或可核查的干预下预测随后已知的事实；用此检验短期校准和机制泛化。反事实长期结果本身不能获得直接真实标签，必须依赖敏感性分析与可证伪子机制检验。

## 四、合适的基准案例

1. **公元前 44 年，凯撒没有遇刺**：验证 BC 后置日期、制度依赖及反事实与现实混淆。
2. **唐朝末年发明蒸汽机**：模糊年代对应点事件，不把“晚唐”错误识别成“几十年渐进发明”。
3. **唐朝末年天下逐渐大乱**：渐进事件必须有开始、发展、建立状态的时间范围。
4. **公元 1234 年，外星舰队降临地球**：地球锚点允许虚构干预，但不是现实信史；下一次 B 分叉可引用外星实体，平行分支不得引用。
5. **公元 1914 年战争被阻止**：防止 1939、1945 的现实事件不经因果分析就默认发生。
6. **公元前 1 年及公元 1 年**：程序内部连续，页面没有 0 年，时间窗不重复。
7. **物理常数在公元 1000 年变化**：只当作用户提出的结构方程干预；如果没有经过校准的物理模块，就不假装精确给出人口、天文学或化学数值。
8. **复合事件相互冲突**：例如相同时刻同一技术被设为“已存在”和“不存在”，必须报告冲突而非随机挑一个。
9. **祖先和后代编辑**：父世界线晚于子分叉的事件不得进入子世界；祖先改写后已存子世界需要标记失效或重演，而不能静默视为正确。
10. **冲突恢复、离线、超预算、断网**：算法失败不应让数据库出现只保存了一半的世界线。

## 五、当前 20 项测试的含义

本交付的 20 项 Node.js 测试使用合成事实、可信的玩具 SCM 和模拟的模型接口，已覆盖基础输入与因果约束逻辑。它们是软件验证，不是历史学界或物理学界的准确率评价。真实模型 API 调用、大规模史料数据、移动端交互以及全量线上回归不在这 20 项之内。

**没有任何研究能保证把现成算法简单组合后，就能精准预演完整的人类历史。** 可靠的路线是：确保可验证硬条件绝不被生成式输出绕过；把可校准机制与无法校准的合理假设分层显示；让用户能够看到因果链、反例和不同假设下的结果差异。
