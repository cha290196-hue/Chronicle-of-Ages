# Chronicle dynamic Earth inference — v3.1

The production entry remains `core.simulate → minute-simulation.simulateMinute`. It creates a complete conditional Earth world through 2026-01-01. The previous engine remains frozen in [archive/ucm-omega-v2](../archive/ucm-omega-v2/README.md).

## Stable content contract

`src/world-output-policy.mjs` defines **dynamic-earth-v1**, independently of model routing and timing parameters. Content grows according to historical duration, activity, causal complexity and worldwide developments. There is no event-count target/ceiling or prescribed description length. The earlier 24–36-event suggestion, 35–65-character descriptions and 80-event rejection have been removed. No fixed proportion of autonomous events is required. Field-level corrections preserve all unchanged event descriptions and regional domain accounts; localized wording defects use exact text substitutions.

The world covers every relevant era and all seven regions. Every region has substantive political, economic, social, scientific/technical, environmental and cultural endpoint states with evidence references: **42 regional domain accounts**, in addition to global settings, dated historical events, initial conditions and causal links. Quiet histories need defensible explanations rather than filler. Later Core questions do not replace the initial historical coverage. Regional details are accessible inside World state → Six domain details.

Events explain causes, prerequisites, mechanisms, consequences and cross-region feedback with as much text as needed. A variable changes the initial state; it is not the topic of every independent regional process. Text is generated once in the selected language. JSON key names, duplicated language fields and repeated snapshot projections are not substantive output volume. Long generated descriptions and summaries survive export/import without the former 2,400/7,000-character prose truncation.

## Performance architecture

One shared causal world is synthesized, then independently audited. Programmatic checks cover exact years, lineage boundaries, causal closure, chronological DAG validity, every global era interval and the seven-by-six regional content structure. Structural defects can first receive a targeted Flash field-patch correction, using actual interventions and temporally eligible evidence. Chronology-only corrections receive the affected records with explicit permitted/forbidden cause IDs instead of a second full-world audit; semantic audits receive the authoritative intervention and year registry. Explicit audit edits undergo the same checks. If a malformed audit or invalid correction remains, one further targeted audit/correction may use the remaining time; the complete world is not regenerated. All calls share a **120-second** deadline, with cancellation and no partial-world commit.

Official DeepSeek generation, audit, corrective audit and migrated saved text profiles use **deepseek-flash**. The retired project preset is no longer offered or invoked. Historical usage/rate records and archived benchmark evidence remain historical records. Extended thinking is disabled in the bounded creation path. Other configured endpoints retain their chosen model except migration of the retired DeepSeek model name.

Official DeepSeek creation and audit requests now use a forced named function with `strict: true` at `/beta/chat/completions`, following the [provider's strict tool-output contract](https://api-docs.deepseek.com/guides/tool_calls/). `src/minute-output-schema.mjs` defines the complete world and patch-control schemas. The bridge reads the function arguments, verifies the envelope and schema locally, then runs the unchanged historical admission, graph, regional/domain coverage and independent-review checks. The function transports structured data; it does not execute code. A provider ignoring this contract fails explicitly rather than silently falling back to free-form text or regenerating the world. Nullable audit placeholders are removed before applying patches so unchanged prose is preserved.

Custom compatible endpoints retain JSON mode and one format-recovery retry inside the same cancellation signal and 120-second deadline. Their endpoint, model and credentials are unchanged. Length-limited output is rejected immediately rather than regenerated at a larger ceiling. Multipart JSON text is concatenated losslessly; the parser no longer invents newline characters inside split strings, and an early closing brace followed by more JSON cannot silently discard the remaining world or audit edits. Resource interruptions, provider cancellation and filtering are reported separately from JSON syntax errors.

The prompt now supplies an actual JSON Schema and literal JSON event example instead of pseudo-JSON type templates. Schemas contain no event-count or prose-length quotas. Historical provider-response replays and synthetic transport tests verify structure, content retention, failure handling and persistence; they do not measure new live API reliability, latency or historical accuracy.

`src/inference-budget.mjs` contains transport headroom (65,536 generation tokens and 16,384 review tokens) and the time budget. These are capacity ceilings, not requested prose lengths or pre-billed token quantities; the model chooses the content required by the separate output policy. These ceilings provide substantial headroom within two minutes. Provider/context capacity and wall-clock limits still physically exist. Hitting a length/time limit is a failure, never permission to prune content or save a partial history.

## Data and causality

The reality timeline is a visual reference through 2026-01-01, not an exhaustive historical database. Exact integer fork years, including years with no marker, are preserved. There is no year zero. Child branches inherit only eligible pre-fork ancestor evidence; parallel worlds do not mix. Automatic initial completion is on by default, records its assumptions and preserves explicit user constraints. Manual mode opens the clarification drawer. Invalid Earth connections, arbitrary magical butterflies and unsupported physical-law changes remain rejectable.

One typed DAG spans background, interventions, inherited knowledge and events. Direct/indirect/independent labels and regional trajectory membership are computed by reachability. Membership indices are refreshed after every causal patch so an event changing affiliation does not leave a stale autonomous index. Autonomous trajectory events cannot descend from the input intervention. Milestones are selected from accepted significant events whose direct or realized downstream causal influence spans regions; no decorative events are invented. Period summaries and snapshots are derived from the same ledger.

Inner simulation format 3 records its output policy, reviewed graph, complete timeline, regional states and timings. Old v2 and earlier v3 worlds remain readable without inventing missing regional detail during migration. The existing outer archive format remains 2. The Analysis Core continues to infer, check and store question-driven conditional knowledge.
