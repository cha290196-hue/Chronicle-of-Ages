# 《岁月史书》UCM-Ω 算法设计

**版本：0.1.0（确定性内核及模型适配层）｜基于 2026-11-08 代码状态**

## 1. 目标与排除项

这是 **现实地球历史的反事实推演**。A 为信史起点至 2026-01-01 的不可变基线，B/C 等为用户干预后的完整世界线。用户在公元 123 年引入事件，B 不是只存在于 123–2026 年，而是在 123 年以前继承 A，之后通过显式因果机制产生差异。同理，C 继承被选择的 B 分支在其再分叉节点之前已经成立的全部事件和事实。

不创造独立于地球历史的新世界，也不把无地球锚点的外星编年当作合法初始编辑。外星人若在公元 123 年到达地球，该干预有效，随后其独特人物和技术成为 B 的分支局部知识。

本引擎不能证明某个千年反事实是“历史必然”。严重超出证据支持范围的推演必须呈现多个情景与认识论不确定性，严禁把模型打分转换为真实概率。

## 2. 数学对象

历史纪年集合：

\[
\mathcal T=\{-3200,\ldots,-1,1,\ldots,2026\}.
\]

程序使用连续刻度 `tick(y) = y+1`（`y<0`）及 `tick(y)=y`（`y>0`），杜绝公元 0 年、重复区间与跨年断裂。

令 \(W_b\) 是完整世界线，\(p(b)\) 为父分支，\(\tau_b\) 为分叉年。逻辑上：

\[
W_b(t)=\begin{cases}W_{p(b)}(t),&t<\tau_b\\
\operatorname{Sim}(S_{p(b)}(\tau_b^-),I_b,t),&t\ge\tau_b.\end{cases}
\]

`resolveAncestry()` 用祖先链和年度严格截断实现前半部分；根分叉后禁止直接恢复现实 A 线的后续历史事件。父分支的 `events/facts` 可复用，但只在早于子分叉的时段有效。

每一历史状态拆为：

\[
S_b(t)=\big(E_b(t),F_b(t),R_b(t),\Theta_b(t),P_b(t)\big)
\]

其中 \(E\) 是事件账本，\(F\) 是具有有效期和互斥语义的事实账本，\(R\) 是可量化资源状态（若有模型），\(\Theta\) 是可信的机制参数（若有校准），\(P\) 是证据与来源元数据（未来知识库模块）。不得从普通文字叙述中假造不存在的 \(R,\Theta,P\) 数值。

用户干预为带时间和实体范围的操作集合 \(I=\{do(X_i=x_i,\tau_i)\}\)，支持独立事件、渐进变化、物理常数修改、分支局部事实修正与复合编辑。真实历史基线本身不参与写操作。

若模型具有已验证的结构方程：

\[
X_{i,t}=f_i\big(\operatorname{Pa}_{i,t},\operatorname{Pa}_{i,t-1},U_{i,t};\theta_i\big),
\]

`stepSCM()` 对当期因果图拓扑排序计算；`do(X=x)` 在指定时刻或期间替代目标方程，其他相关方程根据新值继续求解；`compareCounterfactuals()` 用同一组外生冲击 \(U\) 比较两个世界，隔离干预造成的差值。非时间切片的当期循环会被拒绝，滞后反馈允许通过 `laggedParents` 表达。

仅当已校准转移模型与观测似然存在时，启用 SMC：

\[
\tilde w_t^{(k)}=w_{t-1}^{(k)}p(y_t\mid x_t^{(k)}),\qquad
w_t^{(k)}=\tilde w_t^{(k)}/\sum_j\tilde w_t^{(j)}.
\]

有效样本量 \(ESS=1/\sum_k(w_t^{(k)})^2\) 过低时按系统重采样。**粒子滤波已经实现，但当前项目缺乏足以支撑全球全时代转移分布的训练和测量数据，不能直接把场景样本称为后验历史概率。**

## 3. 输入解析：不用孤立关键词猜意图

建议模型先按相互独立的维度解读自然语言：

| 维度 | 候选值 | 示例 |
| --- | --- | --- |
| 行为意图 | 施加干预 / 提问 / 无关输入 | “唐朝末年蒸汽机出现”是干预 |
| 变化机制 | 点事件 / 累积演化 | 发明蒸汽机是点事件；社会秩序衰败是渐进事件 |
| 作用对象 | 人物、国家、机构、技术、自然过程、物理参数 | 一个输入可能包含多个对象 |
| 干预类型 | 历史改写 / 地球虚构进入 / 常数变更 / 分支事实修订 | 分支特有科技不能无条件加入 A |
| 时间精度 | 精确年 / 日期 / 区间 / 朝代或末期 / 相对与模糊 | “晚唐”是时间范围，不等于渐进变化 |
| 约束 | 必须、禁止、先于、同时、不得改变 | 形成复合干预条件 |
| 依据 | 已有证据 / 估计 / 用户假设 | 未核实推断不能伪装为信史 |

适配层 `simulateOmega()` 使用原有 `callChat` 对输入生成结构化操作；`compileInterventions()` 强制核对地球锚点、分叉时序、缺失实体与复合冲突。自然语言解释的事实正确性仍需独立史料核查，这一步不是万能真值判断器。

## 4. 传播与因果闭合

**不让生成模型直接写进世界账本。** 模型只提出“候选事件/事实”；每一事件必须有唯一 ID、合法年、原因 ID、可选事实前置依赖和明确来源类别。

每个候选事件的因果图是一张按时间允许同年排序的有向无环图（DAG）。程序拒绝：

- 不存在的原因、来自未来的原因、回路、缺失前置技术、条件尚未成立的先决事实。
- 两个同时有效、互斥而数值或状态不同的事实；无穷数值、负数资源账面余额与单位不符的方程干预。
- 不在当前分段内、落在公元 0 年、超出 2026 上限的事件。
- 先前被拒的事实或事件被后来事件依赖的情况。通过闭包求解反复剔除无效依赖。

生成空白窗口是允许的；某个世纪没有重要新事件不等于模型失败。若模型提供了全部不合格事件，可进行**一次带诊断理由的修复请求**，仍然失败就保留拒绝记录，而不是悄悄改写日期和来源。

这套逻辑能阻止一部分形式化错误，但它不会自动判断“某王朝是否因财政枯竭而解体”。语义因果的有效性还需要知识库、可验证结构方程、反例检验、专家审阅及高质量史料。

## 5. 多时间尺度

`adaptiveWindows()` 使用密度靠前的非等长时间窗；近分叉点分辨率更高，远期按较长区间处理。历史关键年可作为切分候选。切分不重叠，并连续覆盖 `firstYear..2026`。未来建议为战争、疫情、经济崩溃等快速动力学引入按事件队列的更小时间步，而对人口、制度、知识积累使用年度至世纪尺度。不同速度的动力学不应该机械等分。

计算预算设定为 `scenarioCount × maxWindows + 分类调用 + 总结调用 + 可选修复调用`。这是 API 请求上界的主要来源。默认两个候选情景、六个时间窗，尚未加入缓存/多智能体子模型；应在实际 API 压测后调整，不可无节制地增加“思考轮数”。

## 6. 多情景而非凭空概率

对相同干预生成 \(K\) 条互不共享其后期事件的轨迹，保留：

1. `preferred`：经当前完整性约束审计分最高的代表性情景。
2. `alternatives`：其他通过相同审计的情景；不是“次真实”分支。
3. `rejected`：违反硬约束的事件及原因。
4. `snapshots`：逐窗推演账本变更和摘要。

`evaluateScenario()` 目前使用显式规则的工程启发式分数，仅衡量局部形式闭合程度。**不能解释为 80% 发生概率，也不是贝叶斯后验。** 在后续数据驱动模型取得独立检验之前，不建议对用户展示任意百分比。

## 7. 前端与存档契约

- A 保持不可写。B、C 都是全跨度世界线；按 2026 末梢选择分支的 UI 规则不需因算法更改。
- 算法仅返回分支结果；存档提交应采用事务式“校验成功后一次落盘”，失败不产生半条世界线。
- 当前 `toLegacyWorldline()` 只负责兼容旧 `events/facts/inherited` 字段；旧 `sanitizeWorldline()` 将裁掉新增 `omega` 及多情景分析。正式上线必须升级存档 schema、支持旧格式迁移，并保留原始因果证据与审计记录。
- 当前 `localStorage` 与图片 base64 共存有额度风险。长期建议结构化记录进 IndexedDB，图像另存 Blob，数据库版本与导入大小限制严格统一。
- 隐私和费用：用户自配 API；发送给模型的应是必要的已选分支上下文，不得无差别上传整份本地存档。

## 9. 审慎命名

可以把整个体系称为 **UCM-Ω（Unified Causal Matrix）**，但在文档和程序中应分清：

- `causal-integrity kernel`：本次实际实现的确定性内核。
- `SCM / particle kernel`：数学工具实现，可在获得可信方程和数据后使用。
- `historical world model`：依赖全球史料、可校准动力学和经验评价的更长期目标，当前不能宣称已实现。
